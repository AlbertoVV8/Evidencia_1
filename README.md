# Evidencia_1
Codigo para evidencia 1 de Java

Instalacion y configuracion
Antes de comenzar, asegúrate de tener instalado lo siguiente en tu sistema:
* **Java Development Kit (JDK) 11** o superior.
* **Git** (para la gestión del repositorio).
* Un IDE compatible (se recomienda **IntelliJ IDEA**).

### Pasos para la Configuración Local

1. **Clonar el repositorio:**
   Abre tu terminal y clona este proyecto en tu máquina local:
   ```bash
   git clone [https://github.com/TU_USUARIO/TU_REPOSITORIO.git](https://github.com/TU_USUARIO/TU_REPOSITORIO.git)
   cd TU_REPOSITORIO
Uso del programa
Al tratarse de una aplicación portátil compilada como un FAT JAR, todas las dependencias están incluidas en un único archivo ejecutable.
Para arrancar la aplicación desde la terminal, navega hasta la carpeta donde se encuentra el archivo .jar generado
